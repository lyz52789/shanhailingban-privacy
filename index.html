山海灵伴隐私政策

版本：1.0｜更新日期：2026-11-14

我们的原则

本应用没有账号体系，没有自有服务器，不收集、不上传你的个人身份信息。你的数据默认保存在你的设备本机。只有你主动启用并配置的功能（如模型对话）才会把对应内容按你的配置发送到你指定的第三方服务。

我们处理的数据

1. 本机保存的数据（不上传）

  • 设置与偏好：视线感知开关、桌面卡片隐私开关等，保存在本机应用数据区。
  • 提醒任务：你创建的提醒标题、内容与时间，保存在本机。
  • 自定义形象素材：你从相册选择的宠物、眼睛、家园背景、休息状态图片，仅保存在本机应用沙箱内，替换或清除即删除。
  • 对话草稿与会话记录：在应用内保存于本机，卸载应用即全部删除。

2. 权限用途（用到才读，不用不碰）

  • 相机：仅“双眼模式”视线跟随时开启，画面在本机处理用于感知视线方向，不拍照、不录像、不上传任何影像。你可以随时在系统设置中关闭。
  • 麦克风：仅在你主动使用语音输入时开启，录音即时在本机转写为文字，不保存录音。
  • 日历：仅用于创建和读取本应用写入的提醒日程（带“山海灵伴”标记），不读取你的其他日程。
  • 照片：仅通过系统选择器选取你主动指定的图片作为形象素材，不扫描相册。

3. 你主动配置后才会发生的数据发送

  • 模型对话：你在“模型服务”中添加并启用第三方模型服务（使用你自己的账号与 API Key）后，你发送的对话内容会按该连接的配置，经 HTTPS 直接从设备发送到对应服务。API Key 仅保存在本机。你未启用模型服务时，不发生任何对话数据发送，应用也不会伪造回答。
  • 上述第三方服务由你自行选择与授权，其数据处理受该服务商隐私政策约束。

4. 到点通知

  • 你创建的提醒以日程形式写入系统日历，由系统在到点时发送通知。通知内容为你填写的标题与时间。

AI 生成内容说明

本应用的虚拟形象“灵伴”及其回复由人工智能生成，不是真人。回复可能存在不准确之处，重要信息请自行核实。连续使用每满 2 小时，应用会提醒你注意休息。

未成年人保护

本应用不面向未成年人提供持续情感陪伴服务。未成年人应在监护人指导下使用；若监护人对孩子使用本应用有疑问或需处理相关事项，请通过下方渠道联系我们，我们将协助处理。

数据的删除与导出

  • 你可以随时在应用内删除提醒任务、清除自定义形象素材、停用模型服务连接。
  • 卸载应用即删除本机保存的全部数据（系统日历中已创建的日程可在系统日历中自行删除）。

权限的撤回

你可以随时在系统“设置—应用—山海灵伴—权限”中关闭相机、麦克风、日历权限；关闭后对应功能不可用，其他功能不受影响。

反馈与投诉

  • 通过应用商店评论区提交反馈与投诉，我们会跟进处理。

政策更新

数据流发生实质变化时我们会更新本政策并在应用内提示。
