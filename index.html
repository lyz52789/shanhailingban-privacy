山海灵伴隐私政策

版本：1.2｜更新日期：2026-11-24

我们的原则

本应用没有账号体系，没有自有服务器，不收集、不上传你的个人身份信息。你的数据默认保存在你的设备本机。只有你主动配置并明确确认授权的功能（如模型对话、工作感知文档整理）才会把对应内容按你的配置发送到你指定的第三方模型服务。

我们处理的数据

1. 本机保存的数据（默认不上传）

  • 设置与偏好：视线跟随开关、工作感知独立授权状态、桌面卡片隐私开关等，保存在本机应用数据区。
  • 提醒任务：你创建的提醒标题、内容与时间，保存在本机。
  • 自定义形象素材：你从相册选择的宠物、眼睛、家园背景、休息状态图片，仅保存在本机应用沙箱内，替换或清除即删除。
  • 对话草稿、记忆与会话记录：在应用内保存于本机，卸载应用即全部删除。
  • 工作感知记录（仅在你于桌面双眼模式主动确认“开启感知”后产生）：本次会话的本机连续录音文件（audio.pcm / audio.wav）、前台陪伴期间录制的本地视频片段（clip-N.mp4）、本机离线语音转写文本及整理后的工作文档草稿/正文，均保存在本机应用沙箱内；不再在磁盘持久留存静态画面截图文件；原始视频与原始录音始终保留在本机，不会上传。

2. 权限用途（用到才读，不用不碰）

  • 相机：
    • 普通陪伴模式默认静态，不开启相机。
    • 仅在你进入“桌面双眼”模式并开启感知后使用前置摄像头：在本机检测人脸位置实现目光跟随；在你明确确认开启“工作感知”后，同一相机流录制本地 .mp4 视频片段（前台可见期录制，切到后台时立即释放相机并封存当前视频片段）。你退出桌面双眼或关闭感知后立即释放相机；也可随时在系统设置中关闭权限。
  • 麦克风：
    • 对话语音输入：仅在你主动点击语音输入时开启，录音即时在本机离线转写为文字，不保存录音。
    • 工作感知记录：仅在你于“桌面双眼”模式经明确弹窗确认“开启感知”后开启（老版本单独开启过视线跟随或语音输入不会自动升级为工作感知录音授权），录音与离线转写保存在本机应用沙箱。在你切出应用但未停止工作感知时，系统通过显式的 AUDIO_RECORDING 后台通知任务维持录音不中断；退出桌面双眼或点击停止感知后立即释放麦克风并终止后台任务。
  • 日历：仅用于创建和读取本应用写入的提醒日程（带“山海灵伴”标记），不读取你的其他日程。
  • 照片：仅通过系统选择器选取你主动指定的图片作为形象素材，不扫描相册。

3. 你主动配置并明确确认后才会发生的数据发送

  • 模型对话：你在“模型服务”中添加并启用第三方模型服务（使用你自己的账号与 API Key）后，你发送的对话内容会按该连接的配置，经 HTTPS 直接从设备发送到对应服务。API Key 仅保存在本机安全密钥库。你未启用模型服务时，不发生任何对话数据发送，应用也不会伪造回答。
  • 工作感知文档整理（文字与可选临时抽帧）：仅当你已在“模型服务”启用支持的服务，并在开启感知或“我的记忆”重新整理弹窗中明确确认目标服务与发送范围后，本应用才会将本次转写文字（以及在“含视频画面整理”或带画面收尾且当前协议支持视觉时，仅在内存中从本机 .mp4 视频临时抽取、压缩后即刻释放且不落盘的有限张画面帧）直接发送到你指定的模型服务，用于生成结构化工作文档；完整视频文件与原始录音仍仅保存在本机，不会发送，也不在应用沙箱留存任何静态截图文件。若接收服务发生变更或停用，本应用会拦截外发并要求你重新确认。
  • 上述第三方服务由你自行选择与授权，其数据处理受该服务商隐私政策约束。

4. 到点通知

  • 你创建的提醒以日程形式写入系统日历，由系统在到点时发送通知。通知内容为你填写的标题与时间。

AI 生成内容说明

本应用的虚拟形象“灵伴”及其回复、工作感知整理文档由人工智能生成，不是真人。生成内容可能存在不准确之处，重要信息请自行核实。连续使用每满 2 小时，应用会提醒你注意休息。

未成年人保护

本应用不面向未成年人提供持续情感陪伴服务。未成年人应在监护人指导下使用；若监护人对孩子使用本应用有疑问或需处理相关事项，请通过下方渠道联系我们，我们将协助处理。

数据的删除与导出

  • 你可以随时在应用内删除提醒任务、清除自定义形象素材、停用或删除模型服务连接；在“我的记忆”中可随时回放本地录音与有声视频、导出工作感知文字记录，或单条删除工作感知记录（同步删除对应本机视频、录音与转写文件）。
  • 卸载应用即删除本机保存的全部数据（系统日历中已创建的日程可在系统日历中自行删除）。

权限的撤回

你可以随时在系统“设置—应用—山海灵伴—权限”中关闭相机、麦克风、日历权限；关闭后对应功能不可用，其他功能不受影响。

反馈与投诉

  • 通过应用商店评论区提交反馈与投诉，我们会跟进处理。

政策更新

数据流发生实质变化时我们会更新本政策并在应用内提示。
